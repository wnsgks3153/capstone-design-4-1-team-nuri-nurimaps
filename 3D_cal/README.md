# NURI BLE-UWB 실내 위치 측정 시스템

## 주요 기능
- BLE(저전력 블루투스)와 UWB(초광대역)를 결합한 하이브리드 기술 적용
- BLE 광고(BLE advertisement)를 통한 동적 앵커(Anchor) 탐색
- 층 정보를 포함한 정밀한 3D 위치 측정
- 모바일 기기를 위한 전력 최적화 구현
- AES-CCM 암호화를 통한 보안 통신
- 다중 태그 및 앵커 지원

## 하드웨어 요구사항
- **태그(Tag)**: ESP32 + DW3000 UWB 모듈
- **앵커(Anchor)**: ESP32 + DW3000 UWB 모듈
- **스마트폰**: BLE를 지원하는 Android 기기 (동반 앱용)

## 폴더 구조
- `3D_cal/`: 3D 위치 측정 구현
  - `3D_UWB_Anchor/`: 앵커 노드 코드
  - `3D_UWB_Tag.ino`: 3D 위치 측정 기능이 포함된 태그 코드

- `Modules/`: 다양한 구현 예제
  - `ss_twr_multi_tag_multi_anchor_with_BLE/`: BLE 지원 예제
    - `ss_twr_initiator_with_BLE/`: BLE가 포함된 태그 구현
    - `ss_twr_responder_with_BLE/`: BLE가 포함된 앵커 구현

- `Apps/`: 모바일 애플리케이션
  - `Android-BLE-ESP32-Example/`: Android와 ESP32 간 BLE 통신 예제
  - `NuriMaps/`: 커스텀 실내 내비게이션 앱

## 설치 방법

### 하드웨어 설정
1. DW3000 UWB 모듈을 ESP32에 연결:
   - SPI 핀 (MOSI, MISO, SCK, CS)
   - 인터럽트 핀
   - 리셋 핀

2. 적절한 전원 공급 장치로 기기에 전원을 공급 (태그에는 LiPo 배터리 권장)

### 소프트웨어 설정
1. Arduino IDE 설치
2. ESP32 보드 지원 패키지 설치
3. 필요한 라이브러리 설치:
   - ESP32 BLE 라이브러리
   - DW3000 UWB 라이브러리
4. 해당하는 .ino 파일 열기
5. 장치 역할 설정 (태그 또는 앵커)
6. ESP32에 코드 업로드

## 통신 원리

### 앵커 탐색 과정
1. 앵커는 BLE 광고를 통해 UWB 주소를 브로드캐스트함
2. 태그는 특정 제조사 데이터가 포함된 BLE 광고를 스캔함
3. 태그는 동적으로 사용 가능한 앵커 목록을 생성함
4. 앵커 주소를 코드에 하드코딩할 필요 없음

### 거리 측정
1. 태그는 각 앵커와 Single-Sided Two-Way Ranging(SS-TWR)을 시작함
2. UWB 신호를 교환하여 비행 시간(time-of-flight)을 정밀하게 측정
3. 비행 시간을 기반으로 거리 계산
4. 정확도 향상을 위해 여러 번 측정하여 평균값 사용

### 3D 위치 계산
1. 태그는 최소 4개 이상의 앵커로부터 거리 정보를 수집 (많을수록 좋음)
2. 3D 삼변측량 알고리즘으로 X, Y, Z 좌표 계산
3. 층 감지 알고리즘을 통해 현재 층 파악
4. 위치 정보는 BLE를 통해 모바일 앱에 제공됨

## 전력 최적화 기능
1. 움직임 기반 BLE 스캔 간격 조절
2. 거리 측정이 없을 때 UWB 절전 모드
3. 유휴 상태 동안 ESP32 경량 슬립 모드 사용
4. 마지막 알려진 위치를 기반으로 선택적 앵커 거리 측정
5. 불필요한 측정을 줄이기 위한 필터링

## 앵커 ID 체계
- 각 앵커는 0~255 범위의 고유 ID를 가짐
- BLE 광고의 첫 번째 바이트에 앵커 ID 포함
- 앵커 위치는 사전에 설정되어야 함
- BLE를 통해 ID와 위치 매핑을 갱신할 수 있음

## 모바일 애플리케이션 통합
Android용 동반 앱 기능:
1. 태그 검색 및 연결
2. 실시간 위치 업데이트 수신
3. 실내 지도에서 사용자 위치 표시
4. 경로 계산 및 안내
5. 위치 정확도 분석 제공

## 문제 해결
- **앵커를 찾을 수 없음**: BLE 광고 및 스캔 설정 확인
- **거리 측정 정확도 낮음**: 장치 간 시야 확보 확인
- **위치가 튀는 현상**: 평균 측정 횟수 증가
- **배터리 소모 많음**: 전력 절약 설정 점검 및 조정
